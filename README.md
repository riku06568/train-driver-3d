# 汐見環状線 3Dトレインシミュレーター (v49)

ブラウザで遊べる本格 3D 電車運転シミュレーターです。汐見環状線のワンマン運転士になって、駅に停車しながら環状線を走らせます。

## 遊ぶ

https://riku06568.github.io/train-driver-3d/

PC・スマートフォンのブラウザで開けます（WebGL / three.js を使用）。

## 検索キーワードについて

検索エンジン（Google / Yahoo / Bing など）で探す際は、**「汐見環状線 3D」** や **「汐見環状線 トレインシミュレーター」**、**「汐見環状線 3Dトレインシミュレーター」** と検索してください。実在の路線と重複しない固有タイトルになっているため、検索エンジンのインデックス登録後に確実に最上位ヒットします。

## 技術メモ

- 単一の `index.html`（HTML + CSS + JavaScript）で動作します。
- 3D 描画は three.js r128（cdnjs の CDN）を読み込みます。オフラインでは動作しません。
- フォントは Google Fonts（DotGothic16 / Zen Kaku Gothic New）を使用しています。
- 車内放送：全路線・全駅の次駅放送・まもなく放送、および全系統案内・運転台タブレット放送（案内・遅れのお詫び・しばらく停車・まもなく発車・ドア閉め案内）を完全事前録音音声（Nanami Neural TTS）で実装。発車直後（次駅放送）および駅手前600m（まもなく放送）のタブレット手動放送化、OS機械合成音声の完全排除を実現。
- 支線運行：支線の運行本数を2倍化（運転間隔を半分に短縮、日中5分/ラッシュ3分/深夜10分間隔）。白峰支線・紫雲地下線・天宮高架線はオンライン同期に対応。港見支線は路線長16km・4駅の短距離ローカル線のためオフライン専用。
- スタート画面：タイトル・乗務・設定・クレジットの3項目メニュー、8種類のランダム背景写真（車内・運転台・沿線風景・駅・夜景）、環状線と支線の階層選択UIを実装。運転画面右上に「タイトルに戻る」ボタンを追加。
- 車内案内表示器（ドア上LCD）：3画面構成（左＝広告、中央＝次の駅・開くドア案内、右＝停車駅一覧・乗換・到着見込み案内）。
- オンラインマルチプレイ（汐見環状線）：MQTT over WebSocket（EMQX Public Broker）を活用した超軽量・リアルタイム同期機能。
  - プレイヤー名登録＆運転席上の3Dネームプレート表示（他プレイヤーの運転台頭上にリアルタイム表示）。
  - 同一線路上で他プレイヤーの前後1km以内の駅を選択不可にするスポーン安全保護。
  - オンライン乗務時はAI電車・ホームのAI乗客を大幅に減らし、プレイヤー同士の運行体験を快適化。
  - 他プレイヤー列車の乗客表示：すれ違う他プレイヤーの全車両に乗客（座席・つり革・立ち客）および運転台の運転士をフル描画。
  - 他プレイヤー列車の立体音響（3Dオーディオ）：距離・方角・速度に応じた走行音（ジョイント音・レール音）、VVVFモーター音、すれ違い時の迫力ある風切音（風圧音）、駅でのドア開閉音、警笛・ミュージックホーンをリアルタイム完全同期。
  - タイトル画面のリアルタイム路線図および運転画面右上の「👥 オンライン」HUDパネルから全プレイヤーの位置・駅・速度を常時確認可能。
  - 本名や個人情報は一切送信・記録されない完全匿名・安全設計。
