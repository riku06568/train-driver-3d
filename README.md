# 汐見環状線 3Dトレインシミュレーター (v49)

ブラウザで遊べる本格 3D 電車運転シミュレーターです。汐見環状線のワンマン運転士になって、駅に停車しながら環状線を走らせます。

## 遊ぶ

https://riku06568.github.io/train-driver-3d/

PC・スマートフォンのブラウザで開けます（WebGL / three.js を使用）。

## 検索キーワードについて

検索エンジン（Google / Yahoo / Bing など）で探す際は、**「汐見環状線 3D」** や **「汐見環状線 トレインシミュレーター」**、**「汐見環状線 3Dトレインシミュレーター」** と検索してください。実在の路線と重複しない固有タイトルになっているため、検索エンジンのインデックス登録後に確実に最上位ヒットします。

## 技術メモ

- 単一の `index.html`（HTML + CSS + JavaScript）で動作します。
- 3D 描画は three.js r128（cdnjs の CDN）を読み込みます。オフラインでは動作しません。
- フォントは Google Fonts（DotGothic16 / Zen Kaku Gothic New）を使用しています。
- 車内放送：全路線・全種別（16系統）および運転台タブレット放送（案内・遅れのお詫び・しばらく停車・まもなく発車・ドア閉め案内）に大阪メトロ風の案内放送を導入（合成音声：Nanami Neural TTS）。発車30秒後の案内放送と駅到着400m前のまもなく放送の2段階放送を実装。
- スタート画面：タイトル・乗務・設定・クレジットの3項目メニュー、8種類のランダム背景写真（車内・運転台・沿線風景・駅・夜景）、環状線と支線の階層選択UIを実装。運転画面右上に「タイトルに戻る」ボタンを追加。
- 車内案内表示器（ドア上LCD）：3画面構成（左＝広告、中央＝次の駅・開くドア案内、右＝停車駅一覧・乗換・到着見込み案内）。
